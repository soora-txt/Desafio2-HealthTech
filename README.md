# HealthTech - CuidarBem 🩺

API REST para organização e acompanhamento de pacientes por cuidadoras autônomas.

## Problema

Cuidadoras autônomas frequentemente organizam informações de seus pacientes de forma
fragmentada — cadernos, mensagens e memória. Isso dificulta consultar históricos,
acompanhar a evolução dos pacientes e responder com clareza a familiares e médicos.

## Solução

O CuidarBem centraliza essas informações em uma API que permite cadastrar pacientes,
registrar atendimentos e detalhar cada visita por categoria (medicação, alimentação,
humor, higiene etc.).

## Tecnologias

- Node.js
- Express
- SQLite (sqlite + sqlite3)
